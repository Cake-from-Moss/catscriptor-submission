# Материалы демонстрации

Состав материалов для проверки (адаптировано под задачу расшифровки):

- видеодемонстрация работы приложения: установка APK, импорт трёх русских аудиозаписей, обработка без
  интернета (режим полёта), экран расшифровки со спикерами и таймкодами, экспорт JSON;
- исходные аудиофайлы и полученные JSON-файлы;
- логи обработки (`adb logcat`) и снимок экрана со стадиями обработки;
- снимок экрана с включённым режимом полёта во время обработки;
- фото или описание устройства (модель, чипсет, объём RAM).

## Статус

Видео в репозиторий не включено: демонстрацию работы приложения команда проводит самостоятельно. Каталог оставлен по шаблону;
если материалы появятся, добавьте их сюда или дайте ссылки. Записи с неподтверждёнными правами не публикуются.

Крупные медиафайлы (`*.mp4`, `*.mov`, `*.mkv`, `*.wav`) в Git по умолчанию не попадают (см. `.gitignore`) —
кладите ссылки или добавляйте принудительно (`git add -f`), если файл небольшой и это осознанное решение.
