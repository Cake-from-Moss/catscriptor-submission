# Артефакты тестирования

- [`results.csv`](results.csv) — сырые измерения. Колонки адаптированы под нашу задачу (шаблонные колонки
  про расстояние и шум относятся к акустической передаче данных и к нам неприменимы):

| Колонка | Значение |
|---|---|
| `test_id` | идентификатор измерения |
| `timestamp_utc` | время запуска (UTC); пусто, если не зафиксировано |
| `commit` | коммит исходников; `n/a`, если не зафиксирован |
| `file_name`, `file_size_bytes` | входной файл и его размер (WAV 16 кГц mono после конвертации) |
| `audio_duration_seconds` | длительность аудио |
| `stage` | что измерялось: `diarization` или `full-pipeline` |
| `processing_seconds`, `rtf` | время обработки и RTF = обработка / длительность |
| `expected_speakers`, `detected_speakers` | число говорящих: известное и найденное |
| `success` | число говорящих совпало с ожидаемым (для `full-pipeline` — обработка завершилась) |
| `device` | где измерялось |
| `notes` | оговорки |

Подробное описание, интерпретация и ограничения: [`../../docs/TEST_RESULTS.md`](../../docs/TEST_RESULTS.md).
Входные аудиозаписи r1–r3 не публикуются (права на фрагменты видео не проверены).
