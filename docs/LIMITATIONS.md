# Ограничения решения

## Поддерживаемые условия

- Устройство: Android 11+ (`minSdk 30`), процессор `arm64-v8a`. Другие архитектуры не поддерживаются.
- Язык: русская речь (ASR — русская модель GigaAM v3). Другие языки не рассматривались.
- Память: нужно около 2 ГБ под APK и ещё примерно 1,4 ГБ во внутреннем хранилище для распакованных
  моделей. Одновременно в оперативной памяти находится одна модель.
- Вход: любой аудиоформат, который декодирует `MediaCodec` устройства. Проверены WAV и M4A.
- Работа без сети: все модели встроены, интернет не используется.

## Известные ограничения

- **Скорость.** На vivo V2538 (Snapdragon 4 Gen 2) сэмпл ~15 с обрабатывался ~35 с (RTF ≈ 2,3), из них
  основная часть — LLM-коррекция 1,5B (≈3,5 токена/с). Замер сделан до смены модели диаризации и на
  одном сэмпле; на длинных записях время вырастет. Уровни «Быстрая» (0,5B) и «Выкл» в настройках
  ускоряют обработку, но замеров RTF по уровням на длинных записях нет.
- **Качество не измерено на размеченных данных.** Размеченного набора русских диалогов у команды нет,
  поэтому WER, DER и ошибка границ на русском не измерены. Число спикеров проверено на 9 записях.
- **Диаризация.** Перекрывающаяся речь не разделяется: каждый момент принадлежит одному спикеру, реплика
  перебившего внутри чужого хода остаётся в тексте владельца хода. Короткая реплика другого спикера
  (< ~1,5 с) внутри непрерывного сегмента может уйти соседу. Точность границ внутри сегмента — около
  ±0,4 с. Параметры кластеризации подобраны на небольшом наборе; на записях с очень длинными
  непрерывными фрагментами речи (дебаты без пауз) результат держится на узком диапазоне параметров.
- **Размер APK.** Около 2 ГБ из-за встроенных моделей. Ограничение организаторов на размер не уточнено.
- **LLM-коррекция** может оставить текст без изменений (защита от галлюцинаций срабатывает осознанно) и
  не гарантирует исправления всех ошибок ASR.
- **Release-сборка** без настроенной подписи (`app-release-unsigned.apk`) не устанавливается; для проверки
  используется APK, собранный командой `assembleDebug` (подписан отладочным ключом).

## Что не входит в текущую версию

- загрузка моделей из сети и удаление встроенной модели (бонус к UX; встроенные модели обязательны);
- обработка в реальном времени как основной режим (есть необязательный Live-предпросмотр при записи);
- системный звук и запись «из других приложений»;
- переход к реплике в плеере по нажатию на реплику;
- разделение перекрывающейся речи и пословные временные метки;
- языки, кроме русского.

## Риски демонстрации

- Первый запуск после установки дольше обычного: модели (около 1,4 ГБ) распаковываются из APK и
  проверяются по SHA-256. Это нужно сделать до демонстрации.
- Время обработки с LLM «Умная» заметно больше длительности записи. Для демонстрации выбирайте короткие
  записи или уровень «Быстрая».
- Устройство, на котором будет идти оценка (чипсет, объём RAM), нам неизвестно; скорость измерена только
  на одном телефоне.
- Фоновая обработка требует разрешения на уведомления (Android 13+) для показа прогресса.

## Дальнейшее развитие

- собрать и разметить русские диалоги (сценарии чистый диалог / быстрые смены / шум и перекрытие), измерить
  WER, DER и ошибку границ, подобрать параметры кластеризации по ним;
- измерить RTF и пиковую память по уровням LLM на целевом устройстве;
- ускорить LLM-этап (меньшая модель, квантование, ограничение объёма правки);
- плеер с переходом к реплике, загрузка моделей по сети как опция.
