# Три сценария записи людьми

**Это задания и реплики-подсказки, НЕ эталонные транскрипты. Аудио ещё нет.**
Можно читать реплики, но лучше пересказать естественно. Разрешены любые
отступления, оговорки и повторения — в reference попадёт только реально
произнесённое. Не копировать этот документ в эталон и не использовать плановые
паузы или номера ходов как таймкоды. Цель каждого файла — примерно 1–3 минуты.
Темп не ускорять искусственно; при коротком дубле продолжить обсуждение.

Перед каждым дублем проверить согласия и отсутствие посторонних голосов.
Два участника — P1/P2; третий для B/C необязателен. Speaker ID назначаются
по фактическому первому появлению в аудио, а не автоматически из этих ролей.
Включить запись, выдержать 2–3 секунды тишины, начать разговор. В конце оставить
ещё 2–3 секунды. Не приклеивать чужое аудио и не смешивать голоса программно.

## A — «Как помочь коту освоиться»

Два человека, тихая комната, телефон неподвижен примерно равноудалённо от обоих
(ориентир 0.5–1 м). Не перебивать. P1 говорит спокойно, P2 чуть энергичнее.
Между некоторыми ходами сделать короткую, между другими — заметную паузу;
не засекать её как эталонный интервал.

| Ход | Роль | Подсказка для произнесения |
|---|---|---|
| 1 | P1 | Сегодня к нам привезли кота. Он пока прячется под креслом. Как думаешь, стоит его позвать? |
| 2 | P2 | Лучше не торопиться. Давай сначала поставим рядом воду и дадим ему осмотреться. |
| 3 | P1 | Хорошо. А миску с кормом оставить у кресла или перенести на кухню? |
| 4 | P2 | Пока оставить здесь. На кухне шумит холодильник, и новый звук может его напугать. |
| 5 | P1 | Да, верно. Я ещё уберу пакеты из прохода и закрою окно. |
| 6 | P2 | А как его зовут? |
| 7 | P1 | Барсик. В приюте сказали, что он любит мягкий мячик и не любит резких движений. |
| 8 | P2 | Тогда положим мячик на пол и отойдём. Пусть сам решает, когда выйти. |
| 9 | P1 | Смотри, он уже выглянул. Кажется, заметил игрушку. |
| 10 | P2 | Вижу. Давай посидим спокойно и не будем сразу его гладить. |
| 11 | P1 | Договорились. Вечером посмотрим, поел ли он и нашёл ли лоток. |
| 12 | P2 | Если всё будет хорошо, завтра начнём понемногу играть. |

Завершить двумя своими вопросами о воде, игрушках или безопасном месте.
Ожидаемые условия A: два различимых голоса, короткие и длинные ходы, разные паузы.
Подтверждать их только после прослушивания файла.

## B — «Собираем переноску к ветеринару»

Два человека, без фонового шума. Короткие ответы чередуются быстро, но **не
требуется overlap**. Междометия произносить естественно, а не удалять из разметки.
У длинных ходов не сокращать слова ради скорости. В трёх местах сделать паузу,
как если бы участники искали вещь или вспоминали время приёма.

| Ход | Роль | Подсказка |
|---|---|---|
| 1 | P1 | Так, переноска где? |
| 2 | P2 | У двери. |
| 3 | P1 | А плед? |
| 4 | P2 | Мм, на полке. |
| 5 | P1 | Этот синий? |
| 6 | P2 | Нет, серый. |
| 7 | P1 | Нашёл. Положить внутрь? |
| 8 | P2 | Да. Только расправь, чтобы лапы не цеплялись за край. |
| 9 | P1 | Угу. Документы взял? |
| 10 | P2 | Сейчас проверю. |
| 11 | P1 | Нам к десяти или к половине одиннадцатого? |
| 12 | P2 | К десяти. Я вчера звонил в клинику и уточнял: сначала осмотр, потом врач решит, нужна ли прививка. |
| 13 | P1 | Ага, понял. Лакомство брать? |
| 14 | P2 | Немного. |
| 15 | P1 | Воду? |
| 16 | P2 | Конечно. |
| 17 | P1 | Ой, кот услышал переноску и убежал. |
| 18 | P2 | Не гонись за ним. Оставь дверцу открытой и положи рядом знакомую игрушку. |
| 19 | P1 | Ладно. До выхода ещё есть время? |
| 20 | P2 | Да, успеваем. Давай без спешки. |

Продолжить коротким обменом: кто несёт переноску, кто закрывает дверь, где ключи.
Для третьего участника P3 можно передать ему вопросы про время и ключи; это
должен быть настоящий человек, а не одна роль, озвученная тем же голосом.

## C — «Выбираем место для кошачьего домика»

Два человека, тихий **собственный** вентилятор или ровный бытовой шум без чужой
речи и музыки. Шум не должен полностью закрывать слова. Не создавать опасный
уровень громкости. Телефон неподвижен; P1 ближе к микрофону, P2 чуть дальше,
но оба слышны. В метаданных указать расстояния и источник шума.

| Ход | Роль | Подсказка и действие |
|---|---|---|
| 1 | P1 | Я думаю поставить кошачий домик возле окна, там утром солнце и достаточно места. |
| 2 | P2 | А рядом с батареей не будет слишком жарко? |
| 3 | P1 | Мы можем немного отодвинуть его от стены. |
| 4 | P2 | Да, но проход останется узким. |
| 5 | P1 | Тогда попробуем у книжного шкафа. Там тихо, и кот сможет… |
| 6 | P2 | **Начать говорить, пока P1 ещё заканчивает:** Подожди, там открывается нижняя дверца! |
| 7 | P1 | **Не останавливаться сразу, закончить вслух:** …смотреть на комнату. А, точно, про дверцу я забыл. |
| 8 | P2 | Можно передвинуть маленький столик. |
| 9 | P1 | Этот? |
| 10 | P2 | Да. |
| 11 | P1 | Хорошо. |
| 12 | P2 | Только сначала уберём провод, чтобы кот не начал его грызть. |
| 13 | P1 | Я уберу провод и поставлю домик чуть дальше от розетки. |
| 14 | P2 | А если кот выберет коробку? |
| 15 | P1 | Значит, рядом будет ещё и коробка. Главное, чтобы ему было спокойно. |
| 16 | P2 | Договорились. Потом посмотрим, где он чаще отдыхает. |

Продолжить обсуждение расположения когтеточки и игрушек своими словами.
Запланированное перебивание не доказывает overlap: прослушать оба голоса
в одновременном участке. Если один участник замолчал до начала другого,
сделать новый дубль целиком; не рисовать наложение в reference. P3 при наличии
может предложить коробку, не нарушая права/согласия.
