# Фикстуры алгоритмов — не аудиодатасет

`reference.json`, `hypothesis.json`, `manifest.json` — искусственные примеры,
созданные для проверки CLI. За ними **нет реальной записи**; эталон не является
ручной расшифровкой аудио. Ожидания: WER = 1/4, DER = 0, MAE границ = 0 мс,
RTF = null. Номера говорящих намеренно переставлены.

Русские диалоги A/B/C с подтверждёнными правами и проверенной разметкой пока
не подготовлены. Наличие этих JSON не закрывает первый пункт issue #11.
Протокол получения настоящего набора: [docs/evaluation.md](../../../docs/evaluation.md).

Не добавляйте сюда приватные разговоры или файлы с непроверенной лицензией.

В [recording-kit/](recording-kit/README.md) подготовлены законченные сценарии
A/B/C, инструкция двум участникам, пустой TSV и невалидированный шаблон
метаданных. Это **не** реальные записи и не проверенные эталоны.
