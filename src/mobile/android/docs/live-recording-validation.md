# Запись, Live и библиотека: отчёт 08.11.2026

Ветка: `feat/live-transcription-recording-ux`, основана на `origin/dev`
`9ab6781ea23299c2b6391517c957b8b92cdfcbe2`. Коммитов и push нет.

## Реализация

- Отмена отделена от остановки: подтверждение, закрытие ресурсов, удаление только
  текущего файла, без импорта. Повторные cancel/stop безопасны.
- Общий `SwipeToRevealDelete` используется на главной и в библиотеке. Свайп
  раскрывает действие, но не удаляет. Доступны Back, закрытие нажатием строки и
  accessibility-действие раскрытия.
- Пятисекундным Undo владеет репозиторий, а не заменяемый snackbar. После окна
  закрываются проигрыватель/обработка и удаляется только файл из собственного
  `filesDir/recordings`. SAF-источники не удаляются.
- `AtomicFile` хранит версионированный снимок библиотеки, результаты, правки,
  имена и tombstone. Прерванная обработка после перезапуска становится ошибкой
  с возможностью повтора, а не фиктивно успешной записью.
- Один `AudioRecord` пишет потоковый WAV и отдаёт копии небольших блоков preview.
  Пауза отбрасывает PCM; время вычисляется из сохранённых сэмплов. Микрофон
  сопровождается foreground service. Полная запись не хранится в RAM.
- Live: настоящие Silero и GigaAM, ограниченные очереди, фразы до 8 секунд,
  нейтральный спикер, максимум 200 строк UI. Это предварительные фразы offline-ASR,
  не streaming-гипотезы и не финальный диаризованный транскрипт.
- Общий gate отдаёт приоритет финальному pipeline и ждёт закрытия Live.
  Состав моделей, веса, параметры финального распознавания и JSON не менялись.
- PCM-кэш теперь закрывается до LLM; накопление ASR-текста использует StringBuilder.
  Исправлена lint-ошибка получения Activity через LocalContext.

## Проверки

Среда: Linux, JDK 25, Android SDK локальный; физический vivo V2538,
Android 16, arm64-v8a, serial `10AG4N0UUK0030L`.

- `assembleDebug assembleRelease test lintDebug` — успешно.
- JVM: 280 тестов, 0 failures/errors, 1 skipped.
- Android: реальная запись с паузой и декодированием WAV; чтение FileProvider;
  stop → очередь → сервис; повторное чтение атомарного снимка с правками и
  tombstone; Undo и удаление собственного файла без удаления внешнего — прошли.
- Отдельно прошла отмена настоящего микрофона после паузы с включённым Live:
  повторная отмена безопасна, файла нет, состояние Idle, импорт не вызывался;
  instrumentation `OK (1 test)`, 3,521 с. Всего семь Android-сценариев прошли
  в отдельных запусках после исправления тестового URI.
- Live на физическом телефоне: тестовый речевой WAV подан в настоящий production
  preview, Silero/GigaAM вернули непустой текст. Первый фрагмент: 128000 сэмплов,
  начало 32 мс, ASR 2642 мс; следующий: 15360 сэмплов, ASR 71 мс.
  Весь тест 15,658 с, включая подачу PCM в реальном темпе и закрытие ресурсов.
  Это проверка работоспособности, не WER и не эталон скорости.
- Первый запуск Live-теста обнаружил неправильный `file://` URI в самом тесте;
  исправлен на настоящий FileProvider `content://`, повторный тест прошёл.
- APK установлен командой `adb install -r`; uninstall/clear не выполнялись.
  Старые M4A на телефоне не удалялись. При обновлении прежние результаты,
  существовавшие только в RAM старой версии, восстановить из отсутствующего
  хранилища невозможно; новые записи сохраняются на диске.
- После последней переустановки и запуска в снимке остались три записи `ready`.
  Финальный фильтр logcat `AndroidRuntime:E RecordingCleanup:E` пуст.

## Ограничения и непроверенное

- Синхронный JNI decode не прерывается мгновенно: выключение/остановка может
  ждать завершения текущей короткой фразы.
- Нет автоматического восстановления незавершённой микрофонной сессии после
  смерти процесса. При исчерпании диска или отказе импорта завершённый файл
  сохраняется, но автоматического повторного импорта нет.
- Повреждённый или неизвестный формат снимка не перезаписывается пустым:
  загрузка завершится ошибкой; отдельного экрана восстановления пока нет.
- Долгий фон, тепловой троттлинг, одновременные приложения с микрофоном,
  многочасовые записи и полный ручной accessibility/жестовый регресс не проверены.
  Несколько строк могут быть раскрыты одновременно; закрытие при прокрутке
  отдельно не реализовано.
- WER/RTF на трёх оценочных русских записях не измерялись; качество preview
  не следует оценивать по наличию непустого текста английского тестового WAV.
- APK не уменьшался за счёт удаления моделей; release-артефакт unsigned,
  для установки использован подписанный debug с настоящими bundled-моделями.
