# Настройка первичной коррекции и метка готовой записи

## Поведение

- «Настройки → Пунктуация и правка» управляет только модельным этапом первичной
  обработки. По умолчанию включён; сохраняется после перезапуска.
- При выключении LLM не загружается. Расшифровка со спикерами и таймкодами становится
  готовой; экспорт остаётся доступным.
- `textCorrected` хранится вместе с записью в атомарном снимке. Устанавливается
  только после успешного завершения этапа и сохранения результата.
- Для готовой записи с `textCorrected == false` действие доступно в контекстном
  меню на главном экране, в библиотеке и в транскрипте. После успешного запуска
  скрывается; повторный запуск также запрещён в контроллере, а не только в UI.
- Ошибка, отмена или конфликт с параллельной ручной правкой сохраняют прежний текст
  без новой метки. Наличие пунктуации само по себе не считается прохождением LLM.
- Старые снимки без поля совместимы: метка `false`, один явный запуск доступен.
- Ручные правки, пометки и переименование не сбрасывают установленную метку.
- Модели, интервалы, спикеры и строгая схема JSON не изменены.

## Проверяемые границы

- JVM: выключенный этап не создаёт корректор; сохраняет исходные реплики и статус
  `Skipped`. Включённый этап закрывает модель и возвращает полный результат.
- JVM: коммит отложенной коррекции устанавливает метку, сохраняет метаданные,
  отвергает конфликт, скрытую запись и уже установленную метку.
- Android: дисковый снимок восстанавливает метку; старый снимок без поля совместим.
- Android: настройка переживает пересоздание репозитория. Тест использует отдельный
  SharedPreferences, не меняет настройки пользователя.
- Android: настоящий foreground service и bundled GGUF корректируют старую готовую
  запись без доступного аудио. Проверяются дисковая метка и отказ второго запуска.
  Данные тестовой записи изолированы от пользовательской библиотеки.

Это проверки управления этапом и хранения результата, не оценка WER или качества
пунктуации на трёх записях организаторов. Полный ручной регресс доступности и меню
на общем телефоне отдельно не выполняется.
