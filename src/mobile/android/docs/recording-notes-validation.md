# Пометки и кнопка остановки — проверка 08.11.2026

Из интерфейса записи убрана подпись WAV; формат аудио остался прежним.
Кнопка завершения записи получила явную подпись «Стоп». Отдельная отмена записи
и пауза сохранены.

Во время записи с Live и без него доступны текстовые пометки и быстрые отметки
времени. При вводе текста позиция фиксируется при открытии редактора. После
обработки пометки доступны над плеером: добавление к текущей позиции,
редактирование текста, удаление и переход к сохранённому времени.

Пометки хранятся отдельно от реплик, в `PipelineEntry.notes`; атомарный снимок
совместим с прежними файлами библиотеки без поля `notes`. При успешной передаче
завершённого аудио в очередь пометки записываются в библиотеку. Отмена микрофонной
сессии не сохраняет её пометки. Строгий JSON экспорта не меняется.

завершилась успешно. JVM: 284 теста, 0 ошибок/падений, 1 пропущен.
