# Тестовые аудиофайлы

Эти синтетические файлы входят только в instrumentation APK, не в приложение.
Каждый содержит одну секунду стереосигнала 440 Гц: амплитуда левого канала
0,25, правого — 0,125. После сведения ожидается амплитуда около 0,1875;
сжатие с потерями допускает небольшое отклонение.

Генерация через FFmpeg:

```bash
ffmpeg -f lavfi -i 'aevalsrc=0.25*sin(2*PI*440*t)|0.125*sin(2*PI*440*t):s=44100:d=1' -c:a libmp3lame -b:a 128k tone-stereo-44100.mp3
ffmpeg -f lavfi -i 'aevalsrc=0.25*sin(2*PI*440*t)|0.125*sin(2*PI*440*t):s=48000:d=1' -c:a aac -b:a 128k tone-stereo-48000.m4a
ffmpeg -f lavfi -i 'aevalsrc=0.25*sin(2*PI*440*t)|0.125*sin(2*PI*440*t):s=48000:d=1' -c:a libvorbis -q:a 4 tone-stereo-48000.ogg
```

Длительность контейнера может включать задержку и дополнение кодека;
проверка должна учитывать gapless-метаданные и фактический PCM-выход Android.
